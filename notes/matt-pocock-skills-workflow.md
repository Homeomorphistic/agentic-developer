# Matt Pocock's skills workflow

## Main flow

Matt Pocock presents a five-step workflow:

1. `/grill-with-docs` — clarify the idea through questions and capture the decisions in documentation.
2. `/to-spec` — turn that documentation into an implementation-ready specification.
3. `/to-tickets` — decompose the specification into small, ordered work items.
4. `/implement` — implement the tickets and verify the work.
5. `/code-review` — review the completed changes against the intended result.

The workflow is a chain: each skill produces the artifact consumed by the next, moving from an initially unclear idea to reviewed code. Sources: [AI Hero: Skills](https://www.aihero.dev/skills), [Matt Pocock's `skills` repository](https://github.com/mattpocock/skills).

**From vague idea to reviewed code**
